## 68 个格式漏判的机制

AGS 的提取顺序为：答案标签、最后一个 answer 标记、最后非空行；随后先识别开头字母，再清理 `is` 等前缀。清理后不会再次提取字母。标记正则中的 `(.*)` 默认不跨行。

| 实际提取现象 | 数量 | 可复核示例 |
|---|---:|---|
| `answer is:` 后换行，最终只提取到 `:` | 25 | ID 1：`The correct answer is:\n\nB. ...`；AGS 为 `:`，明确最终选项为 B |
| 其他标记后换行，提取到说明文字 | 4 | ID 319：提取 `would be:`；下一段为 `C. 40 meters` |
| 清理 `is` 后剩下 `A. ...` / `B. ...`，未重试字母识别 | 24 | ID 88：`Thus, the correct answer is A. Red.`；提取 `A. Red.` 而非 A |
| 最后行以 `Thus,` 开头，字母不在行首 | 12 | ID 36：`Thus, B. No` 被整段保留 |
| 其他标记残留 | 3 | ID 491：`related to the question is A. Yes.`；ID 493：`: A. Towards us.`；ID 755：`related to the question is: A. Straight ahead.` |
| 合计 | 68 | |

前两类共 29 题在答案标记处截断，未读取随后明确给出的答案行。后三类共 39 题虽保留了正确答案文本，但没有规范成选项字母。

AGS 的选项文本后备匹配还存在大小写不对称：标准答案对应的选项文本调用 `.lower()`，`pred_extracted` 在这一分支没有调用 `.lower()`。因此 `no` 无法匹配 `B. No.`、`red` 无法匹配 `A. Red.`。逐题检查确认，上述后三类 39 题都满足“小写化当前已提取字符串后，正确选项文本可以匹配”。这是机制诊断，不是替换官方得分或修改官方代码的结果。

## 官方 substring 后备分支及其反向误判

AGS 先比较提取结果和标准答案。若未匹配且提取结果不是合法的小写单字母，它读取 **标准答案标签所对应的选项文本**，再执行：

```python
correct_option_text in pred_extracted or pred_extracted in correct_option_text
```

它还对数字选项提供数字词及 zero/no 的后备判断。这里 reference 用于评测匹配，不是传给生成模型；但这个分支直接根据 reference 决定布尔正确性，并不先独立承诺一个唯一选项。它没有检查“其他选项是否也在回答中”或“模型是否明确拒绝作答”。

本批 461 个 AGS 正确结果由 438 个直接比较通过和 23 个选项 substring 通过组成；数字词后备分支未贡献额外通过样本。23 个 substring 通过中，22 个也被统一解析器判正确，剩余 1 个为 ID 507：

> 模型明确表示无法从图像选择答案，并列出 `(A. 34, B. 35, C. 36)`。

其 reference 为 B、对应选项文本为 `35`。AGS 因 `35` 出现在列出的选项中而判正确。统一解析器保留未明确选择的状态，判错误。这说明 AGS 既可能漏判明确答案，也可能放行含正确选项字样的未作答输出；不能把其全部差距都解释成统一解析器“更宽松”。

官方 stdout 文件没有输出这些逐题错误。源码仅在 `answer.lower()` **不属于**合法选项字母时收集 show-errors；本批 reference 全为字母，因此即使 `show_errors=765` 也不会打印 MCQ 错例。日志中没有错例明细不代表没有错误。

## 差距集中于证据后长回答

以下使用已归档 `with_evidence` 标记：

| 子集 | 题数 | AGS 正确 | 统一解析器正确 | 格式恢复 / 反向取消 |
|---|---:|---:|---:|---:|
| 有框证据输出 | 141 | 27 | 85 | +58 / 0 |
| 无框证据输出 | 624 | 434 | 443 | +10 / -1 |

有框证据回答平均约 77.7 个空白分隔词，无框证据回答约 6.3 个。AGS 对有证据回答中的 136/141 未提取为合法单字母；无证据回答对应为 26/624。这个分布说明当前 FaithAct 解释性输出格式与该规则解析器不兼容。它不证明框证据提升或损害了模型准确率；该结论需要与同样本的 CoT 答案做配对比较。

## 报告口径

保留 AGS 原始官方分数 60.2614%，同时报告统一、reference-blind 答案提取后的 69.0196%。后者需对所有方法使用同一规则，且保留完整原始输出和逐题差异。不能以较高数字覆盖官方输出，也不能将这 8.7582 个百分点描述为方法或提示词带来的生成提升。两个数字都不是对 FaithAct 原论文分数的严格复现成功声明。
