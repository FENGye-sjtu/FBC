# V13 online：三个正确初答退化案例的轨迹诊断

日期：2026-09-22。只读来源：`tmp/analysis/v13_online_full.jsonl` 与 `tmp/analysis/cases.jsonl`。本报告不修改模型、阈值、生成输出或运行中的 V14。尚未独立读取完整 V13 CF 输出，因此下列轨迹结论只适用于已完成的 online 运行。

## 计数口径

765题数据集中的这16题是已反复查看的工程样本，不是独立测试集。15题有明确初始答案，其中8题初始正确；随后2题由错改对（ID 1、8），3题由对改错（ID 9、12、15），因此该15题最终正确7题。ID 7没有明确初始答案，最终补答正确，另计1题。全16题最终正确8题。无初始答案的补答不计为纠正。

三个退化案例共同出现以下轨迹：正确初始答案被原图支持检查拒绝，独立重读生成新的长复合描述，该描述获得高支持分。两个案例把该描述存为 verified 后通过不确定综合作答返回错误答案；另一个案例直接通过全部最终检查返回错误答案。

| ID | 初始正确答案 | 初始支持分 | 首次改错位置 | 最终错误答案与状态 |
|---|---|---:|---|---|
| 9 | A：5.5米 | 0.182426 | step 0 / repair 1 提出 B | B：9.5米；uncertain，verified-ledger synthesis |
| 12 | B：车头在右侧 | 0.119203 | step 0 / repair 3 提出 A | A：车头在左侧；uncertain，verified-ledger synthesis |
| 15 | B：2辆车 | 0.106691 | step 0 / repair 1 提出 A | A：1辆车；verified_by_model |

这里“正确”只指明确答案与数据标签相同。支持分是模型的 Yes/No 决策分数，不是已校准的正确率。

## ID 9：宽泛场景描述被保留，未通过的距离答案在最终综合中再次出现

问题要求 pickup truck 与最近路缘的水平距离，reference 为 A（5.5米）。

1. 初始候选为 A，claim 表示卡车靠近路缘、距离较小。原图支持分0.182426，判 contradicted。
2. 首次独立重读使用 full+crop，crop占全图面积约4.519%。重读文本达到600字符，说明卡车、多车道、路缘等背景，并明确表示缺少尺度、无法确定准确距离；`evidence_complete=false`。
3. 生成器把重读复制成299字符复合claim，结尾为未完成的 `clearly separated from`，同时提出 B。该claim支持分0.851953，进入verified ledger；答案蕴含分仅0.042088，因此B被扣留。
4. 下一step先拦截重复verified claim，再尝试deduction B，蕴含分0.006693，未通过。随后三个视觉修复都直接主张9.5米，其支持分依次为0.201813、0.201813、0.037327，均未通过，最终该距离点记为uncertain。
5. 三次重复已耗尽问题后触发finalize。记录明确为 `source=verified_ledger_synthesis`；综合模型返回B。此处没有最终答案审计，整体状态如实保留uncertain。

可证实的是：9.5米从未通过答案蕴含或原图支持检查，但最终综合仍选择了它。获得verified标签的是宽泛且不完整的场景描述，不能仅凭reference判定该描述每个背景细节都错；它也没有建立9.5米这一结论。不能把该案例描述为“9.5米通过了验证”。

该题共有6个audit事件。选项一致性检查执行0次，因为其前置蕴含检查都未通过。最高支持度候选fallback也没有执行：已有verified背景描述使流程选择了ledger综合路径。

## ID 12：错误方向的长claim比同方向短claim得到更高支持

reference为B，即车头在图片右侧。

1. 初始短claim“车头在右侧”回答B，支持分0.119203，被拒。
2. repair 1和2都使用同一个占全图约82.167%的大crop。重读均判断朝右且 `evidence_complete=true`；候选仍为正确B，但支持分均为0.320821，被拒。
3. repair 3改为完整原图重读，第一次改成朝左。候选是300字符长描述，含车头、车轮、后端、吊臂等多个断言，末尾截在 `The vehicle's branding and`。其支持分0.924142，标记verified。答案A的蕴含分0.754915未达现有门槛，所以只扣留答案、保留错误方向claim。
4. 下一step的deduction A以0.651355失败；两个full+crop修复又恢复正确B，但较长的朝右claim仍只有0.592667。最后一个完整原图修复返回短claim“车朝左”，支持分0.622459，未通过。
5. 该问题随后记为uncertain并被重复问题限制拦截；finalization再次使用 `verified_ledger_synthesis`，从包含错误朝左描述的ledger生成A，整体状态uncertain。

本题明确存在与reference相反的朝左视觉断言被标记verified。尤其值得注意：同一完整原图视图下，包含朝左判断的300字符复合claim支持分为0.924142，后来的63字符朝左claim仅0.622459。视觉audit提示不读取ledger，因此两次已记录的检查主要差异在claim文本，不能把这一差异解释为来自新外部证据。它证明支持判定明显依赖被核验陈述的表述及附带内容；还不能据此断言内部注意力机制或所有附带细节都具有某种确定因果作用。

该题共有8个audit事件，选项一致性检查执行0次。最后也没有使用最高支持度候选fallback。不能将这次退化归因于选项一致性评分或单纯的“crop分辨率太低”：正确的朝右判断在full+crop重读中重复出现，第一次方向改错发生在完整原图重读。

## ID 15：局部计数成为全局计数，所有现有检查共同放行

问题询问对向车道仍在行驶的车辆数，reference为B（2辆）。

1. 初始候选明确回答2辆，原图支持分0.106691，判 contradicted。
2. repair 1局部框为 `[0.223799, 0.497653, 0.333019, 0.605663]`，约占全图1.180%。full+crop重读说在Image 2中看到一辆银色轿车，并推断没有其他对向车辆、仅一辆仍行驶；`evidence_complete=true`。
3. 修复候选变为A（1辆），claim共299字符，将局部对象、运动推断、其他车辆不存在等内容合成一段，末尾同样不完整。支持分0.914901，答案蕴含分0.904651，均通过。
4. 独立选项一致性评分也选择A：A=-0.539617，B=-1.039617，C=-2.789617。因此直接返回A并标记 `verified_by_model`，没有进入finalization。

“只有1辆”的claim与reference冲突且被标记verified。重读明显依赖很小的局部框，并把局部可见数扩展为整个问题范围的车辆数；这是可见的计数范围风险。不过输入仍含完整图像，不能声称其他车辆的像素完全未提供。也没有同图同文本、仅改变分辨率的对照，因此不能把错误独立归因于像素预算。

本题的online非遮挡路径把完整原图传给 `check_final`，因此这里的独立选项评分使用完整原图，不是只用crop。它没有挽救错误，也没有主动把B改成A：候选在它运行前已经是A，支持和答案蕴含也已通过。若只删掉这次一致性检查，按已记录的前置gate结果仍会返回A。

该题只有2个audit事件，没有耗尽预算或fallback决策。

## 能归因到什么，不能归因到什么

| 解释 | 现有证据支持程度 |
|---|---|
| 正确初答被支持检查拒绝，触发修复 | 三题均直接成立 |
| 修复时出现长复合claim并被verified | 三题均直接成立；长度为299、300、299字符 |
| 重读产生与reference冲突的新判断 | ID12、15直接成立；ID9首先产生不能确定尺度的背景说明 |
| 选项一致性把正确答案主动改错 | 不成立：9、12没有执行；15运行前已经是错误A |
| 最高支持度uncertain fallback造成退化 | 不成立：9、12走verified-ledger synthesis；15直接通过 |
| 完整ledger综合能重新输出被扣留的答案 | ID9、12直接成立，且最终状态仍标uncertain |
| 所有错误都来自crop低分辨率 | 无法成立：12在完整原图重读时首次改错；没有分辨率单变量对照 |
| 遮挡反事实检查可以或不能修复这些例子 | 本报告没有完整CF轨迹证据，不作结论 |

配置文件声明NF4、总 `max_pixels=1003520`。双图输入共享总预算，完整场景与crop的各自上限相应减少；此实现事实不等于已确认的实际错误原因。这里没有从现有记录恢复逐图实际视觉token数。

## 最小下一步

保持当前V14运行完成并保留其独立结果。若随后只做一项针对本次证据的实现修正，应将**repair候选落实为当前证据问题对应的一条原子断言**，把重读中的背景解释保留在tentative修复上下文而不整体复制进被核验claim。三题当前被接受的claim均为接近300字符上限的复合、未完成句，ID12还提供了同原图下长短表述支持分显著不同的直接轨迹证据。

这不是调整通过阈值，也不预言修改后必然恢复三题。V14当前只改变首次提议提示；它能检验初始提议变化，但不能单独隔离或修复repair仍复制长重读的机制。后续判断应保留相同模型和图像预算，检查三题的原子claim是否仍被误放以及全16题是否引入新退化；不依据这三个已查看案例声称泛化提升。
