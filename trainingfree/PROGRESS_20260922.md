## Evaluation-protocol result and newly exposed prompt conflict

Fresh BF16 inference on the 765-row VLMEvalKit RealWorldQA packaging completed at
539/765 = 70.46% with the common final-answer parser and the official AGS rule
scorer, only +0.36 points from FaithAct Table 2's 70.1% CoT value. In contrast,
the original xai mixed-format inference was 479/765 = 62.61% (AGS: 478/765).
This isolates dataset/prompt packaging as the dominant gap in the earlier 62.61%
run, but does not finish CoT parity: VLMEvalKit's own "Please select" directive
caused most outputs to be a bare option despite the appended reasoning request.

The current pinned VLMEvalKit `can_infer` exact scorer gives 513/765 = 67.06%.
All 26 disagreements are correct explicit answers that repeat the same letter at
the start and after `FINAL ANSWER`, which its first-occurrence heuristic rejects.
Both numbers and per-case logs are retained. A score-only mapping of old outputs
to the new labels is 278/765 = 36.34% and is explicitly not a reproduction result.

The multi-GPU FaithAct smoke succeeded on case 0 using an externally hashed CoT
cache. A later failure was source-traced to Transformers retaining Qwen2.5-VL
`rope_deltas` on one shard while Accelerate dispatched `cache_position` to the
other. The adapter now aligns them immediately after dispatch; the clean v4 run
passed the former case-9 failure. That pass was then stopped at 261/765 because
only 11 blank-line reasoning steps existed in its first 219 inputs: it was mostly
re-answering direct outputs, not running the intended FaithAct algorithm. The
conflicting directive is now removed and a clean reasoned CoT -> FaithAct queue
is active. No FaithAct benchmark score is claimed.

## Implemented response to these actual failures

1. A visual step may include an answer. Its claim receives the visual audit and
   its answer receives an independent entailment/option-mapping check.
2. Removed placeholder JSON strings that small models copied verbatim.
3. Localization now belongs to a separate call; internal normalized ledger boxes
   are not fed to the proposer as pixel-coordinate examples.
4. Repair changes evidence: independently reacquire a region and inspect full
   scene plus enlarged crop. Three attempts progressively broaden crop context.
5. CF masks are propagated into both global and zoomed views; no unmasked crop
   leaks the evidence being removed. Total image-token budget is held fixed.
6. Model instances persist between development jobs; stateless controller/prompt
   revisions reload between jobs, avoiding repeated 8–11 minute weight loads.

New job results must be checked under `runtime/workers/{7b_dev,3b_dev}/results`.
Old traces are not relabeled as results of the repaired method.
